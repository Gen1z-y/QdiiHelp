# 隐私与公开发布

## 本次公开源码范围

公开内容为程序源码、依赖清单、人工构造的测试、通用教学文档、图标及占位配置。

以下本机内容不属于公开源码，并由忽略规则排除：

- config/database.local.json 和其他本地连接配置、环境文件。
- 数据库、导出数据、真实关注列表、个人金额和交易记录。
- 日志、运行报告、备份、归档压缩包和已编译 EXE。
- 本机截图、图片素材、研究原始记录和历史协作记录。
- 依赖目录、编辑器私人配置和系统文件。

本机数据库不会因上传源码自动上传；但手动导出、截图或打包仍可能把其中的信息带出来。不要把整个日常运行目录作为发布包。

## 占位配置与测试

database.example.json 中的本机地址、数据库名称和 replace-me 都是教学示例，密码应在自己的本地配置中填写。

测试会使用人工构造的金额、基金代码、行情与持仓字段，供验证兼容与计算逻辑；这些值不是公开的个人账户记录。模拟预览的列表和行情同样为测试场景。

## 后续提交前

```powershell
git status --short
git diff --cached --stat
git diff --cached
git ls-files
```

检查文件清单和实际内容。不要使用 git add -f 强制提交私人文件。忽略规则对已跟踪文件不生效，改了 .gitignore 也不会从历史中删除秘密。

提交作者使用项目名或公开网名，邮箱可使用 GitHub 的 noreply 地址。公开 GitHub 仓库仍会显示所有者的公开账号信息；源码排除私人资料不能隐藏 GitHub 账号本身。

没有扫描能绝对证明任何内容永远不含隐私。每次新提交都应重新检查；若已经泄露凭据，应先撤销或轮换，删文件并不能撤回已被复制的内容。

## 反馈问题

请提供复现步骤、版本、预期和实际行为。日志只截取必要片段，删除密码、连接串、邮箱、用户名路径、自己的基金列表和个人截图。不要在 Issue、讨论或 PR 中粘贴本地数据库配置或完整导出文件。

## 本地运行边界

项目默认监听本机回环地址，未提供多用户鉴权。不要直接反向代理到公网或公开数据库端口。

程序获取真实行情时会向第三方数据源发送所查询的基金或证券代码；这与将私人运行数据库上传 GitHub 是不同的数据流。使用外部接口前请了解其隐私和使用条件。
