# 日常操作教程

## 从空列表开始

完成数据库初始化后，进入本地页面，输入六位基金代码添加基金，再按需要放入持有、自选或债基分组。分组表达你的观察分类，不需要录入账户、个人金额或交易记录。

先少量添加并完成一次刷新，确认自己的网络可以访问数据源，再逐步扩展列表。

## 刷新与同步持仓

“刷新数据”获取基金资料、正式净值、行情和估算；股票估算使用本机已经同步的披露持仓。也可以使用分类旁的刷新入口，仅更新指定分组。

首次添加股票型基金后，如果提示没有持仓快照，进入“基金持仓”执行“更新持仓并估算净值”。它会获取最新可用披露、更新适用基金的持仓并重新估算。同步报告里可查看成功、失败、无变化和暂停估算的原因。

基金披露持仓是基金公开报告中的股票或债券明细，不是使用者的证券账户持仓。披露存在滞后，不代表基金经理当前实时组合。

普通刷新、强制重算与同步持仓的目的不同。重新计算不会把已公布数据改造成事前预测，也不会覆盖已封存的原始估算。

## 读懂卡片

- **目标净值日期**：当前估算对应的净值归属日。
- **基准净值**：计算收益所使用的起点。
- **预估**：已获取披露持仓、行情及汇率下的模型参考值。
- **正式结果**：数据源已公布、可按日期核对的基金净值。
- **覆盖率与缺失提示**：说明模型掌握多少信息，不代表准确率。
- **校准参考**：样本足够时按历史平均偏差提供的另一个参考数值，不替换原估算。

详情可查看计算说明、历史走势、持仓贡献和误差样本。预估缺失时先查看原因；过期持仓、零股票占比或关键行情缺失都可能暂停估算。

## 日期与假期

T 日净值可包含北京时间 T 日晚至 T+1 日凌晨的海外行情。普通周末与国内长假采用不同展示规则，不应直接把画面日期当作海外交易日。

长假累计会明确基准日、目标日与行情截止日。阶段累计并非完整的节后首日预测，等待完整收盘和正式基准后再核对。

## 历史、对比与导出

历史图表用于观察正式净值和已有的单日估算。基金对比选择 2–8 只基金，按共同区间查看涨跌与回撤；起点、分红、折算和数据源口径可能造成与其他平台不同的结果。

全球指数入口提供不同市场指数的点位及走势，缺失或延迟行情会单独提示。

导出图片用于保存当前显示结果。分享前自己检查基金清单、分组、时间等信息，因为这些内容可能体现个人关注偏好。

## 正常退出

命令行运行时按 Ctrl+C 并等待保存；托盘运行时使用右键“退出”或“停止后台”，等待在途任务完成。不要把强制结束进程作为常规停止方式。
