# QdiiHelp

本地运行的基金净值观察与学习工具，支持 QDII 股票基金、指数基金及部分债券基金的估算、正式净值核对、历史走势和披露持仓分析。

后端使用 Node.js 与 PostgreSQL，前端使用原生 JavaScript；Windows 用户可自行构建托盘入口。仓库提供源码和模拟测试数据，不包含作者的数据库、关注列表、私人配置、运行日志或历史备份。

## 能做什么

- 按持有、自选、债基分组管理基金，手动刷新全部或指定分组。
- 获取公开披露持仓，结合行情与汇率计算参考估值，展示覆盖率、数据日期及缺失原因。
- 记录公布前的估算，正式净值公布后按日期核对，查看样本误差与历史校准参考。
- 查看历史净值、基金对比、全球指数及交易日历，导出带水印的结果图片。
- 将业务状态、快照、行情缓存、日志与应用备份存入本机 PostgreSQL。

估值受披露滞后、费用、汇率口径和数据源可用性影响；部分基金会暂停估算。它用于学习与观察，不承诺准确率，也不提供交易执行功能。

## 先体验：不用配置数据库

安装 Node.js 22 或以上版本，在项目目录运行：

```powershell
npm ci
npm run preview
```

打开 [模拟体验页面](http://127.0.0.1:8790/)。

这里使用人工构造的基金数据和模拟行情，状态写入系统临时目录；不代表真实收益或线上行情。按 Ctrl+C 停止。预览可能留下临时文件，不会自动清除所有测试文件。

## 安装并使用真实行情

1. 下载本仓库 ZIP 并解压，或运行 `git clone https://github.com/Gen1z-y/QdiiHelp.git`。
2. 安装 Node.js 22+ 与 PostgreSQL，进入项目目录执行 `npm ci`。
3. 创建自己的空数据库，复制连接配置并填入自己的账户。
4. 按[完整安装教程](docs/getting-started.md)初始化空数据库。
5. 执行 `npm start`，打开 [本地页面](http://127.0.0.1:8787/)。

**首次使用必须初始化数据库。** 仅创建数据库和复制配置文件还不能启动。新安装从空关注列表开始，需要自行添加基金。

源码仓库不附带 `QdiiHelp.exe`。Windows 托盘使用方法及构建命令见[托盘教程](docs/tray-app.md)；普通源码体验直接使用上述 Node.js 命令即可。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 按锁文件安装依赖 |
| `npm run preview` | 8790 端口模拟体验，不需要数据库 |
| `npm start` | 使用自己的 PostgreSQL 启动真实服务，默认 8787 |
| `npm test` | 运行自动测试，默认跳过 PostgreSQL 集成测试 |
| `npm run db:migrate -- <外部state.json绝对路径>` | 首次初始化或从旧格式导入；不用于覆盖已有数据库 |

程序默认只监听 `127.0.0.1`。当前没有多用户账户或面向公网的鉴权体系，请按本机工具使用。公开源码不等于公开个人运行实例。

## 数据来源与限制

程序按功能使用东方财富/天天基金、腾讯、NAVER、Frankfurter/ECB 等外部数据源；它们可能延迟、限流或不可用。仓库不附带个人运行时下载的数据集。源码许可证不授予第三方数据的再分发权，使用和再分发数据前需另行确认相应来源的条件。
